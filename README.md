## Github Repository
https://github.com/nofoobar/fastapi-course

## Technology Stack: 
- Asynchronous webserver: uvicorn 
- git & github hosting out code base
- For executing unit tests : pytest
- GO to ORM's in python world: SQLAlchemy
- Using Postgres
- WebApp : Jinja2 Templates

## Initial Configurations for the Project: 

- To create virtual environment
python -m venv env
- To activate virtual environment
.\env\Scripts\activate 

## Find Running processes on windows on a given port: 

netstat -aon | find ":8000"

## Kill running processes on windows: 
taskkill /PID <PID> /F

## Start Fast API backend application: 
uvicorn backend.main:app --reload --port 8001

## Using Alembic: 
alembic revision --autogenerate -m "Create user and blog table"
#### This is so as to create tables from the alembic autogenerated file
alembic upgrade head

## Using Python Interpreter playing with DB: 
from backend.db.base import User
from backend.db.session import get_db
db = get_db().__next__()
db.query(User).all()
